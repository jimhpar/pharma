                ADORZOTNO PHARMA POS & STOREFRONT - SETUP GUIDE

[EN] How to run this project on any Windows PC:
[BN] যেকোনো নতুন কম্পিউটারে প্রজেক্টটি খুব সহজে যেভাবে চালাবেন:

--------------------------------------------------------------------------------
1. কম্পিউটারে যা যা ইনস্টল থাকতে হবে (Prerequisites)
--------------------------------------------------------------------------------
প্রজেক্টটি চলার জন্য কম্পিউটারে নিচের ২টি সফটওয়্যার থাকতে হবে:

১. Laragon (অথবা XAMPP) - PHP এবং MySQL ডাটাবেজের জন্য:
   - Laragon Full ডাউনলোড করুন: https://laragon.org/download/
   - অথবা আগে থেকেই কম্পিউটারে PHP (8.2+) ও MySQL থাকলে চলবে।

২. Node.js (LTS Version):
   - Node.js ডাউনলোড করুন: https://nodejs.org/ (LTS ভার্সন)

--------------------------------------------------------------------------------
2. প্রজেক্ট যেভাবে চালু করবেন (How to Start)
--------------------------------------------------------------------------------
সবচেয়ে সহজ পদ্ধতি:
১. পুরো "pharma-main" ফোল্ডারটি পেনড্রাইভ থেকে কম্পিউটারে (যেমন: Desktop বা C: ড্রাইভে) কপি করুন।
২. Laragon ওপেন করে "Start All" বাটনে চাপ দিন (অথবা MySQL চালু রাখুন)।
৩. ফোল্ডারের ভেতরে থাকা "start.bat" ফাইলটিতে ডাবল ক্লিক করুন!

ব্যস! স্ক্রিপ্টটি স্বয়ংক্রিয়ভাবে:
- PHP, Node এবং MySQL ডিটেক্ট করবে।
- যদি ডাটাবেজ ইমপোর্ট করা না থাকে, তবে অটোমেটিক "adorzotno" ডাটাবেজ তৈরি করে সম্পূর্ণ ডাটা ইমপোর্ট করে নিবে।
- ৩টি সার্ভার (Storefront 3000, POS Admin 8001, API 8000) ব্যাকগ্রাউন্ডে চালু করে ব্রাউজারে সাইট ওপেন করে দিবে।

--------------------------------------------------------------------------------

৩. ব্যাকএন্ড এপিআই (API Server):

--------------------------------------------------------------------------------
সার্ভারগুলো বন্ধ করতে ফোল্ডারে থাকা "stop.bat" ফাইলে ডাবল ক্লিক করুন।
